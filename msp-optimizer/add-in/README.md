# Phase 2 — read-only COM add-in source
Target: Windows x64, Microsoft Project 2016, .NET Framework 4.8. This is uncompiled source, not an installer. Build on Windows with the .NET 4.8 Developer Pack and actual Office/Project PIAs: msbuild UniversalMspOptimizer.csproj /restore /p:Configuration=Release /p:OfficePiaPath="C:\path\to\PIAs". Verify all interop signatures and dependencies on the target host. Register only a verified DLL with 64-bit RegAsm /codebase and the MS Project Addins registry key for UniversalMspOptimizer.Connect (LoadBehavior=3). Use a test copy of an MPP. Ribbon opens a standalone read-only Windows Forms window, not a native docked pane. No schedule mutations, event automation, network requests or persistence. Candidate classification is preliminary, not authorization to modify tasks. Next: test actuals including assignment-level actuals, localized NA values, external tasks, constraints, calendars and manual scheduling; implement bridge and transactional optimizer separately.
