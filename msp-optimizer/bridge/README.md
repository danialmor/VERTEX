# Local bridge v1
Read-only snapshot endpoint: GET http://127.0.0.1:18765/v1/snapshot. Start explicitly from MSP Ribbon; consent required. A fresh random bearer token is shown locally. Stop from Ribbon or close MSP. Snapshot captured on MSP UI thread at start; restart to refresh. No COM calls on HTTP worker thread. Exact origin allowlist, loopback binding, no storage or upload. GitHub Pages origin is shared across danialmor repositories: token is the actual authorization boundary. Never paste token into other pages. Browser local-network permission, HTTP loopback support and Windows HTTP.sys URL ACL may be required; test on target Windows/browser. No write endpoints. No live synchronization yet.
