# Experimental installer
Use Windows with Visual Studio Build Tools, .NET Framework 4.8 Developer Pack, Inno Setup 6 and licensed Microsoft Project 2016 x64 PIAs. Place Extensibility.dll, office.dll and Microsoft.Office.Interop.MSProject.dll in a local directory; do not commit proprietary DLLs. Run build.ps1 -OfficePiaPath C:\PIAs. The setup prerequisite check is heuristic, not proof of Project bitness or version. Close Project before install/uninstall. Unsigned experimental installer; do not bypass organizational security controls. No automatic scheduling writes. Test only on disposable saved MPP copies. Local recovery files and lock profiles remain after uninstall. GitHub workflow uses a manually provisioned self-hosted Windows runner with label msp2016-build; never run untrusted PR code on it. No runner or installer is provisioned by this commit.

## All-in-one 0.5.1 beta
Build machine only: obtain official Microsoft .NET Framework 4.8 offline redistributable from https://dotnet.microsoft.com/en-us/download/dotnet-framework/net48 and save as prerequisites/dotnet48.exe. Build validates Authenticode. Do not commit binaries. End users need only the generated VERTEX-MSP-Setup.exe, supported Windows x64 and licensed Project desktop x64. Setup embeds runtime, skips if 4.8 or newer, handles restart and performs COM registration. Interop embedding is configured but must compile and pass clean-machine tests before release; if embedding fails, resolve API types or use licensed redistributables. Browser local network permission, token pairing and HTTP URL ACL remain separate runtime checks. No automatic WBS writes. No compiled package yet. Test clean Windows, missing runtime, x86 rejection, uninstall, and dashboard connectivity.
