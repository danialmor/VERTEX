# Experimental installer
Use Windows with Visual Studio Build Tools, .NET Framework 4.8 Developer Pack, Inno Setup 6 and licensed Microsoft Project 2016 x64 PIAs. Place Extensibility.dll, office.dll and Microsoft.Office.Interop.MSProject.dll in a local directory; do not commit proprietary DLLs. Run build.ps1 -OfficePiaPath C:\PIAs. The setup prerequisite check is heuristic, not proof of Project bitness or version. Close Project before install/uninstall. Unsigned experimental installer; do not bypass organizational security controls. No automatic scheduling writes. Test only on disposable saved MPP copies. Local recovery files and lock profiles remain after uninstall. GitHub workflow uses a manually provisioned self-hosted Windows runner with label msp2016-build; never run untrusted PR code on it. No runner or installer is provisioned by this commit.
