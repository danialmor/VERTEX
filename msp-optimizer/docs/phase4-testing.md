# Phase 4 validation gate
Experimental manual preview/apply only on disposable local MPP copies. Trial edits occur in the open project, even in preview; do not use production files. Backup is last saved disk state, not unsaved state. Rollback restores candidate durations and checks selected fields; it is not a complete transaction. No assigned tasks supported, no automatic writes, no claim of full baseline or assignment protection. Bounded binary search assumes locally monotonic finish response; failure is not proof of infeasibility. Test serial/parallel paths, calendar gaps, protected milestones, actuals, multiple locks, constraints, leveling, exceptions and restoration on Project 2016 x64. Automatic enforcement remains gated until those tests pass.
