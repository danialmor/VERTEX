# Architecture
VERTEX UI -> authenticated local Windows bridge -> COM add-in -> Microsoft Project. Bridge must bind loopback only, validate origin and session token, and require local consent. No direct browser COM. Per-project/WBS locks use stable project identity and task UniqueID. Equal optimization distributes remaining-duration changes among eligible tasks and recalculates the actual schedule network. Preserve actuals, dependencies, milestones and baseline; reject infeasible targets and roll back failed transactions. Phase 1 is UI/config scaffolding only; no live connection or schedule edits. Phase 2: implement and test bridge and COM on Project 2016 x64; then package installer.
