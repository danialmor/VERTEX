# Phase 4 — safe optimizer foundation
EqualPlanner generates uniform signed minute changes with individual lower bounds. It does not infer finish dates from aggregate duration. LockProfiles persists local per-file/summary UID targets; moving/renaming or copying MPP requires explicit re-identification. Local profile data is not uploaded to public GitHub. No automatic schedule writes are enabled.
Required next implementation: run trials on an isolated MPP copy with actual MSP recalculation, compare full finish timestamps, detect nonmonotonic network effects and infeasible targets, verify actuals (including assignments), baseline, dependencies, milestones, constraints and out-of-scope impacts. Only after validation implement transactional apply with recoverable backup, audit, and guarded change detection. Do not treat a generated candidate as a feasible schedule. Minimum duration and maximum extension must be user-configurable before production.
