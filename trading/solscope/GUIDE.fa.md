# راهنمای فارسی · SolScope (یافتن بهترین تریدرهای سولانا)

## این چیست؟
یک داشبورد که بهترین کیف پول‌های سولانا را از جدول‌های امتیاز GMGN پیدا می‌کند و در یک جدول نشان می‌دهد: سود محقق‌شده، درصد برد، میانگین زمان نگهداری، تعداد معامله و پیوند مستقیم به GMGN. برچسب خودکار نهنگ، پول هوشمند و ربات هم دارد.

## چطور کار می‌کند
مرورگر ← سرور کوچک پایتون (`server.py`) ← API سایت GMGN ← برگشت به مرورگر.
سرور فقط واسطه است تا محدودیت مرورگر (CORS) و محافظ Cloudflare رد شود.

## راه‌اندازی
1. Python 3 و نصب وابستگی‌ها: `pip install -r requirements.txt`
2. اجرا: `python server.py` ← روی پورت `8080` (یا متغیر `PORT`).
3. مرورگر: `http://سرور:8080` ← دکمه‌ی **Auto-Discover**.
4. اجرای دائمی: `gunicorn server:app` (فایل `Procfile` آماده است؛ روی Railway هم با `railway.json` بالا می‌آید).

## تغییری که ورتکس داد
سرور اصلی هر نشانی اینترنتی را واسطه‌گری می‌کرد (هر کسی می‌توانست از سرور شما سوءاستفاده کند). در این نسخه فقط نشانی‌های `gmgn.ai` مجاز است.

## نکته‌ها
- کیف پول‌های ذخیره‌شده در همان مرورگر می‌مانند.
- اگر GMGN از ایران در دسترس نباشد، سرور را در کشور دیگری بگیرید.
- این ابزار فقط تحلیل است و معامله انجام نمی‌دهد.

## وضعیت در ورتکس
سرور آن را در محیط آزمایشی اجرا کردم و صفحه‌ی اصلی درست بالا آمد. برای کار واقعی سرور لازم است.
