# راهنمای فارسی · CCXT (اتصال یکسان به صدها صرافی)

## این چیست؟
کتابخانه‌ی استاندارد برای کار با بیش از ۱۰۰ صرافی کریپتو با یک زبان یکسان: قیمت، دفتر سفارش، کندل، موجودی، ثبت و لغو سفارش. برای جاوااسکریپت، پایتون، PHP، C#، Go و Java. Freqtrade و بسیاری از ربات‌ها روی همین ساخته شده‌اند.

## همین حالا در مرورگر
تب «زنده» همین ماژول، CCXT را مستقیم در مرورگر شما اجرا می‌کند و قیمت، دفتر سفارش و کندل‌ها را از صرافی می‌گیرد — بدون کلید و بدون سرور (فقط داده‌ی عمومی).
در آزمایش ما **OKX، Kraken و Bitget** جواب دادند؛ بعضی صرافی‌ها مثل Binance و Bybit به درخواست مستقیم مرورگر یا به آی‌پی ایران جواب نمی‌دهند.

## استفاده در برنامه‌ی خودتان
- پایتون: `pip install ccxt`
- جاوااسکریپت: `npm install ccxt`
نمونه‌ی پایتون:
```python
import ccxt
okx = ccxt.okx()
print(okx.fetch_ticker('BTC/USDT')['last'])
```
برای سفارش واقعی کلید API صرافی لازم است (`apiKey`، `secret`) — فقط روی سرور، فقط با اجازه‌ی ترید و **بدون اجازه‌ی برداشت**.

## کجا چه چیزی هست
- `wiki/Manual.md` — راهنمای کامل (انگلیسی)
- `examples/js` و `examples/py` — صدها مثال
- `dist/ccxt.browser.min.js` — نسخه‌ی مرورگر که تب «زنده» از آن استفاده می‌کند
