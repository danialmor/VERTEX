# راهنمای فارسی · GMGN Skills

## این چیست؟
مجموعه‌ای از «مهارت»ها (Skill) و یک خط فرمان از سایت GMGN برای عامل‌های هوش مصنوعی (Claude Code، Sim و…). با آن عامل می‌تواند توکن‌های داغ، توکن‌های تازه، اطلاعات و امنیت یک توکن، کیف پول‌های پول هوشمند و KOLها را ببیند و در صورت نیاز سفارش خرید و فروش بدهد. شبکه‌ها: SOL، BSC، Base و ETH.

## چه چیزهایی دارد
- **۱۹ مهارت** در پوشه‌ی `skills/` — هر کدام یک فایل `SKILL.md` که به عامل می‌گوید چه کار کند (مثلاً `gmgn-token` برای تحلیل توکن، `gmgn-swap` برای خرید و فروش، `gmgn-track` برای ردیابی پول هوشمند).
- **۹ گردش‌کار آماده** در `docs/` (گزارش روزانه، هشدار ریسک، بررسی کامل توکن و…).
- **خط فرمان** `gmgn-cli` (کد در `src/`).

## راه‌اندازی (روی سرور یا رایانه‌ی خودتان)
1. نصب Node نسخه‌ی ۱۸ یا بالاتر.
2. نصب خط فرمان: `npm install -g gmgn-cli` (یا برای توسعه در همین پوشه: `npm install` و `npm run build`).
3. گرفتن کلید API از `gmgn.ai/ai` و نوشتن آن در فایل `~/.config/gmgn/.env`:
   `GMGN_API_KEY=...`
4. فقط اگر می‌خواهید سفارش ثبت کنید: کلید امضای `GMGN_PRIVATE_KEY` (این کلید کیف پول نیست، کلید امضای درخواست‌های API است). دسترسی فایل را با `chmod 600` ببندید.
5. برای عامل: پوشه‌ی `skills/` را به Claude Code یا Sim بدهید.

## نمونه دستورها
- توکن‌های داغ یک ساعت اخیر سولانا: `gmgn-cli market trending --chain sol --interval 1h`
- اطلاعات یک توکن: `gmgn-cli token info --chain sol --address <آدرس>`
(فهرست کامل: `docs/cli-usage.md`)

## هشدارها
- کلیدها را هرگز در این سایت، مرورگر یا مخزن ننویسید؛ فقط در فایل `.env` روی سرور.
- خرید توکن‌های میم بسیار پرخطر است.
- دسترسی به GMGN و صرافی‌ها از ایران ممکن است مسدود باشد؛ سرور را در کشوری بگیرید که دسترسی دارد.
